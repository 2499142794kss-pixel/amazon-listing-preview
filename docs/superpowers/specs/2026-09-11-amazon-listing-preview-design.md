# Amazon Listing 图片预览工具设计

## 目标

构建一个本地运行的单页工具：用户一次选择或拖拽多张图片后，工具依据文件名和图片尺寸自动分类、排序，并渲染为接近亚马逊商品详情页的纯图片预览。图片只在浏览器内处理，不上传服务器。

## 核心流程

1. 用户将图片拖入上传区域或点击选择图片。
2. 浏览器读取图片文件，提取文件名、尺寸和本地预览 URL。
3. 文件按名称识别为橱窗图或 A+ 图：1500×1500 归入橱窗；1464×1200 归入 A+ 首图/KV；1464×600 归入 A+ 后续内容；尺寸不匹配的图片仍保留，但在上传区给出轻量提示。
4. 组内按文件名中的数字序号自然排序，支持 `-1`、`-2` 以及 `A+3-2` 这种组号/轮播序号。没有可识别序号时按文件名排序。
5. 右侧或下方实时渲染纯图片详情页：主图/橱窗图区域、缩略图切换、A+ KV、以及按组拆分的 1464×600 横幅轮播区。每个 A+ 组只占一个大横幅容器，组内图片按 `-1`、`-2` 等序号横向轮播。

## 页面结构

- 深色工具壳层，左侧为上传与素材状态，右侧为浅色亚马逊页面预览。
- 上传区支持拖拽、高亮反馈和“一键清空”。
- 预览默认显示第一张橱窗图；缩略图点击切换主图。
- A+ 区块完全由图片组成，不额外渲染文字说明、标题或说明卡片；轮播只显示图片、箭头和圆点状态。
- 无图片时显示简洁空状态；有图片后尽量避免任何会抢占预览面积的说明。

## 技术边界

- 使用原生前端（HTML/CSS/JavaScript），零后端依赖，便于直接双击或通过静态服务器运行。
- 使用 `URL.createObjectURL` 生成本地预览，并在清空/替换时释放 URL。
- 通过文件名正则做序号解析：末尾数字作为排序尾序；`A+3-2` 先按组号 3，再按轮播序号 2。
- 图片显示使用 `object-fit: contain`，不裁切原图。
- 响应式布局：桌面双栏，窄屏上下布局。

## 验收标准

- 可以一次选择或拖入多张图片，并立即看到预览。
- 1500×1500、1464×1200、1464×600 图片分区正确。
- `-1` 在 `-2` 前；`A+3-2` 在同组 `A+3-3` 前；组号按自然数排序。
- 可以切换橱窗主图，A+ 图片按排序顺序展示，预览只出现图片内容。
- 清空后所有本地预览释放，页面回到空状态。
